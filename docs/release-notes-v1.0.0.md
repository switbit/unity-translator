# v1.0.0 — первый публичный релиз

Первый публичный релиз **Universal Unity Translator** — плагина для BepInEx 5, который переводит текст Unity-игр прямо в интерфейсе.

## Что внутри

- `UnityTranslator-Setup.exe` — установщик с автоматической установкой BepInEx 5.4.23.6 (x86/x64).
- `UnityTranslator-1.0.0.zip` — установщик, README, лицензия и DLL для ручной установки.
- `SHA256SUMS.txt` — контрольные суммы SHA-256 для всех файлов.

## Возможности

- TextMeshPro, uGUI Text и TextMesh.
- Автоопределение языка исходного текста и целевого языка Windows.
- Замена текста в игре, без оверлеев.
- Кэш переводов и шрифтовой fallback для нелатинских языков.
- Безопасная работа с «печатающимся» текстом и послайдовыми катсценами.
- Горячая клавиша **F5** — вернуть оригинал и заново применить перевод.
- Провайдеры Google Translate и LibreTranslate.
- Настройки задержек, минимальной длины строки и исключений по именам сцен и объектов.

## Исправлено

- Зависание катсцен и `IndexOutOfRangeException` в `CutsceneUI.ApplyReveal`, когда перевод применялся во время анимации раскрытия текста.
- Некорректное отображение текста при быстром пропуске диалогов.
- Замена текста после «длинных кадров» и подвисаний игры.

## Требования

- Windows 10/11.
- Unity-игра на **Mono** (x86/x64). IL2CPP не поддерживается.
- BepInEx 5.4.23.6 — устанавливается автоматически.
- Интернет для Google Translate или собственный LibreTranslate.

## Установка

1. Скачайте `UnityTranslator-Setup.exe`.
2. Укажите папку игры.
3. Нажмите «Установить переводчик».
4. Запустите игру.

> Установщик не подписан сертификатом: Windows SmartScreen может показать предупреждение. Проверить файл можно по `SHA256SUMS.txt`.

## Известные ограничения

- Не работает с IL2CPP, UI Toolkit, NGUI, FairyGUI и собственными системами вывода текста.
- Не переводит текст, «запечённый» в текстуры, видео и 3D-модели без `TextMesh`.
- Плагин собран против reference-сборок Unity 6; для заметно более старых версий Unity может потребоваться пересборка.
