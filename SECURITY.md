# Безопасность

## Как сообщить об уязвимости

Не создавайте публичный issue для проблем безопасности. Используйте
[GitHub Security Advisories](https://github.com/switbit/unity-translator/security/advisories/new) или напишите
владельцу репозитория.

Опишите:

- версию плагина и игры;
- шаги воспроизведения;
- возможные последствия;
- при наличии — минимальный пример или лог.

## Что важно знать

- Плагин загружается в процесс игры через BepInEx и патчит методы Unity.
- Переводимый текст отправляется на выбранный сервис перевода
  (по умолчанию Google Translate).
- Кэш переводов хранится локально в `BepInEx\config\UnityTranslator\`.
- Установщик не подписан сертификатом; проверяйте SHA256 по файлу
  `SHA256SUMS.txt` из релиза.
