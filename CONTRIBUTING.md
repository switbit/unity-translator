# Участие в проекте

Спасибо за интерес к Universal Unity Translator.

## Сообщения об ошибках

Перед созданием issue:

1. Проверьте, что игра на **Mono**, а не на IL2CPP.
2. Посмотрите `BepInEx\LogOutput.log` — там часто есть готовая причина.
3. Приложите:
   - название и версию игры;
   - версию Unity (видна в логе BepInEx);
   - `LogOutput.log`;
   - `BepInEx\config\ru.unitytranslator.cfg`;
   - скриншот проблемного места.

Если проблема связана с конкретной сценой, укажите её имя — его можно добавить
в `[Text] ExcludedNames` как временное решение.

## Pull request

1. Форкните репозиторий и создайте ветку от `main`.
2. Внесите изменение и проверьте сборку:

   ```powershell
   $env:UNITY_MANAGED_DIR = "C:\Games\MyGame\MyGame_Data\Managed"
   powershell -ExecutionPolicy Bypass -File tools\build-release.ps1
   ```

3. Проверьте плагин в реальной Unity-игре: интерфейс, катсцены, быстрое
   пролистывание диалогов, F5.
4. Опишите в PR, что изменено и как это проверялось.

## Стиль кода

- C# 9, `netstandard2.1`, без внешних NuGet-зависимостей.
- Публичные API Unity вызываются только после проверки на `null`.
- Любой новый хук должен быть обёрнут в `try/catch` и не ломать игру при ошибке.
- Не перезаписывайте `StringBuilder` и другие объекты состояния игры.
- Для новых настроек добавляйте описание в `README.md`.
